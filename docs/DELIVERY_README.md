# 光庭：五关完整版

基于本次提供的《光庭.html》扩展，不覆盖原文件，不使用旧版俯视工程替代它。
保留原人物、动画、E/F交互、放灯下落和前三关；镜头改回纪念碑谷式固定俯视机位。

第四关：绿光接替青光维持前桥，青光接替白光维持后桥，腾出的白光开启出口。
第五关：红灯放绿台、绿灯放红台，利用不同高度的接收器建立自动往复循环，再乘绿台抵达上层红门。
第五关采用残墙入口、左转绿廊、绕墙升降庭、二层出口的分段揭示，不是一条直接暴露的通道。
第三、第四关完成后均可登乘光舟前往下一关。第六关尚未制作。

五关的机关现在是同一个构件（`mechanism.js` 的 `buildMechanism`）：一只低低的烛台（0.8 石底盘 + 短柱），
台面只到晶石中心下方 0.3 米，上面托一颗目标颜色的八面体晶石；烛台圆环与晶石都取该机关需要的颜色。
晶石中心统一在 0.52 米：手持灯的光束在 0.45 米，放在地上的灯在约 0.3 米，两者都在命中半径内，且都不会被台子自己挡住。
第一关原本的雕花接收器、第二三关的灰晶石与方墩底座都已改成这一形制，第二关为白（#e5f3ff）、第三关桥控为品红（#ec85ec）、双锁为红与蓝。

灯具本身也是同一个模型：各关都克隆第一关的灯体，并在克隆后显式设为可见
（离开第一关时模板会被隐藏，之前第三、四、五关因此只剩下光束、没有灯体）。

所有放置灯具的台子都已取消：灯直接停在地上（约 0.3 米）等待拿取，放下也是自由落到地面，
落地后按真实落点自动水平朝向最近可见的机关（看不到任何机关时保留你放灯时的朝向），落点本身不再有任何吸附。第一关的灯座与灯台、第二三关的地面灯座、第四关的供能站与灯台、
第五关的台上灯座与灯台都已移除；第五关升降台只保留一圈细环标出的台面凹槽（不算台子，灯落在凹槽上随台升降）。

所有固定灯座（第一关灯座、第二三关地面灯座、第四关供能站、第五关台上灯座）都已去掉：
灯可以一直拿在手里——面朝机关走过去，光束就会落在晶石上；也可以随时放下，落地后自动朝向最近可见的机关。

左下角的「原光色环」是光学三原色的三圆叠加（红+绿+蓝 → 黄 / 品红 / 青，三色齐亮中心为白），由 `orbits.js` 的 `setColorOrbits()` 驱动：
手上拿什么颜色就亮什么颜色（第一关蓝光、第二三关按手持灯的位、第四关按手持灯的掩码、第五关按手持灯的位），放下灯后回到暗光谱色。
熄灭时三圆保持暗光谱色（暗红 / 暗绿 / 暗蓝，交叠处是暗黄 / 暗品红 / 暗青），点亮后换成高亮纯色并带辉光；圆与圆之间用 CSS 的 `mix-blend-mode:screen` 混合。

每一关开场都有一段运镜：镜头先停在终点位置给一拍近景（视距拉近到 20），再用约 2.5 秒平滑移回人物初始位置并把视距拉回 45，
用来先告诉玩家「终点在哪里」。任意按键或点击画面都会立即跳过运镜；自动验证模式（`?verify=1` 等）不播放，避免影响镜头相关用例。

自动用例：第一关 21/21、第二关 18/18、第三关 18/18、第四关 23/23、第五关 32/32（`?verify=1&campaign=1&third=1`、`?verifyfour=1&verifyfive=1`）。

## 构建与验证

`tools/unpack.py` 是一次性导入工具，重新运行会覆盖提取后的 engine.js 与 main.js（含已改造的机关），请勿用于日常构建。
日常运行 `tools/build.py` 生成 app.js、index.html 和内嵌所有资源的单文件 HTML。
`tools/verify_package.py` 校验原文件未修改、12份资源字节一致和既有关卡模块保持不变。
单文件脚本可用 `node --check checked-standalone.mjs` 检查语法。

`?verifyfour=1` 执行第四关完整流程、错误顺序、失电、落水、落灯与固定俯视镜头检查。
`?verifyfour=1&verifyfive=1` 联测第四、第五关；第五关额外检查循环、18个站位遮挡、灯具与角色随台、夹人保护、转角揭示和镜头避墙。
`?verifyfive=1&view=lower` / `view=upper` / `view=overview` 是检查机位，不是正常试玩镜头。
`?verifyfour=1&view=overview` 提供仅用于检查布局的拉远镜头；正常试玩是固定俯视机位，随角色平移并可在第五关被墙遮挡时抬高视角。

镜头是正交轴测（等距 2.5D）沙盒机位：默认斜俯视整个关卡，左键拖动可绕角色旋转，滚轮 / 双指可缩放视野，相机始终跟随角色平移并保留玩家转过的角度；第五关在墙体挡住视线时会把相机移到墙前（正交投影不改变画面大小）。
试玩操作：WASD / 方向键沿关卡轴向移动，Shift 加速，E/F 拾取、放下；握灯时光束朝人物正面，用鼠标或 ◎ 把人物转向机关即可照射。

浏览器工具不能直接访问 file://，因此单文件做静态完整性与语法校验，本地服务版做实际运行测试；不宣称文件协议模式已实测。

本地服务命令：
```sh
python3 -m http.server 8770 --bind 127.0.0.1
```
